# 🎬 Inception

> "An idea is like a virus. Resilient. Highly contagious."

## **Overview**
A thief who steals corporate secrets through dream-sharing technology is given the inverse task of planting an idea into someone's mind.

- **Genre:** Sci-Fi / Action
